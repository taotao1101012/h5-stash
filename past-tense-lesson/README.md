# 英语语法动画课 · 一般过去时 × 过去进行时

一个单文件、零依赖的语法教学 H5：像看视频一样讲「一般过去时 / 过去进行时」的区别，再用 `when / while` 把两个时态连成句子；英文例句内嵌真人朗读（离线可用），最后有闯关练习。

## 打开方式

- 在线：<https://taotao1101012.github.io/h5-stash/past-tense-lesson/>
- 本地：直接双击 `index.html`，或在本目录起一个静态服务：

```bash
cd past-tense-lesson
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 页面结构（8 幕）

| 幕 | 内容 |
| --- | --- |
| 开场 | 双色标题 + 关键词浮签 |
| 一般过去时 | 定义、公式 V-ed、不规则动词、信号词、时间轴「一个点 ●」 |
| 过去进行时 | 公式 was/were + V-ing、ing 变化、时间轴「一条线 ▬」 |
| 一眼看懂 | 同一句话两种讲法 + 双时间轴 + 对照表 |
| when 连句 | 小剧场：🧑看书 ⚡电话响 → `was doing + when + did`（长被短打断） |
| while 连句 | 双线平行 `While was doing, was doing`（两长同时）+ when/while 对照表 + 口诀 |
| 闯关练习 | 5 道题，答错有提示可重试，答对出解析，结算页自动进总结 |
| 总结 | 公式回顾 + 决策树 + 口诀 + 现学现用的金句 |

全程双色标注：🟠 过去式 = 短动作 / 完成，🔵 进行时 = 长动作 / 进行。

## 交互

- **🖐 默认手动模式**：底部「下一步 ▶」每点一下出一条内容，点出例句时自动朗读；一幕点完后按钮变「下一幕 ⏭」。空格 / → 同效，← 上一幕，手机可左右滑动。
- **⏩ 自动播放**：右上角 🖐/⏩ 一键切换，回到"视频式"自动走片。
- **🎬 动画小剧场**：when / while 两个场景是会动的迷你动画（读书动作、电话铃声波纹、人物惊跳、闪电打断、TV 闪光、"同一时刻"虚线拉出），进场自动播一次，「🔁 再播一遍」随时重看。
- **朗读**：播放到例句分镜自动读出（内嵌 AAC 音频，Samantha 美音、语速 150）；例句旁 🔊 可单独重读；顶栏 🔊 开关控制自动朗读；声音被浏览器拦截时点一下页面任意位置即恢复。
- **音效**：剧场开场"啵"、电话铃、答对叮咚、答错低嗡，全部合成内嵌（共 26KB）。
- **练习**：答错给提示可再试，答对出解析（带音效）；结算显示一次答对数 + 彩带，自动跳总结。
- **导航**：底部圆点直接跳幕；键盘 ←/→/空格；进度条实时显示。

## 自定义

所有内容都在这一个文件里，改完刷新即可。

- **例句 / 文案**：直接搜 HTML 里的文本；`data-say` 属性就是要朗读的句子。
- **换音色 / 语速**：用 `say -v <音色> -r 150 -o 句子.aiff "句子"` 重新生成，`afconvert -f m4af -d aac 句子.aiff 句子.m4a` 转码后 base64 塞回脚本里的 `var AUDIO=`。
- **加题目**：复制一个 `.q-card`，改题干和选项，正确选项加 `data-ok="1"`，解析写在 `.q-exp` 里。
- **换配色**：文件顶部 `:root` 里的 `--past`（🟠 过去式）和 `--prog`（🔵 进行时）两个变量控制。

## 技术说明

- 单文件：HTML + CSS + 原生 JS + base64 内嵌音频，无外部字体、图片、库或构建步骤。
- 播放引擎：requestAnimationFrame 时间轴按 `data-delay` 逐镜揭示；暂停时冻结 CSS 动画；手动 / 自动双模式共享同一套分镜。
- 音频解码后走单个复用的 `<audio>` 元素，规避移动端"每次播放都要手势"的限制。
- 已测：1000×760 桌面、414×896 手机模拟；自动播放连续、朗读零拦截、无 JS 报错。
