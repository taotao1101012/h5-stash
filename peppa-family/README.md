# 小猪佩奇 · 我们这一家

一个单文件、零依赖的移动端 H5 家庭相册页：用佩奇一家的四个角色、三张「小日子」明信片和一张全家福，讲一个关于普通下午的故事。

## 打开方式

直接双击 `index.html` 即可，或在本目录起一个静态服务（推荐，避免个别浏览器对 `file://` 的限制）：

```bash
cd peppa-family-h5_active
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

手机预览：让手机和电脑连同一个 Wi-Fi，访问 `http://<电脑局域网 IP>:8000`。

## 页面结构

| 区块 | 内容 |
| --- | --- |
| Hero | 雨后天空、太阳/云/风筝、四只小猪全家站在山坡上 |
| Intro | 「一家人，就是一起把普通的下午 / 过成值得记住的日子。」 |
| 成员 × 4 | 佩奇、乔治、猪妈妈、猪爸爸：编号、名字、英文名、性格标签、口头禅、小传、小秘密 |
| 一些小日子 | 雨天的伞、睡前故事、周末野餐三张手绘明信片 |
| 全家福 | 胶带相框、彩虹、全家福、「一起跳泥坑」彩蛋按钮 |

每个成员区块的插画可以点：小猪会跳一下，并冒出一句它的口头禅。

## 交互

- **点击/键盘激活角色**：触发一次小跳 + 对话气泡（2.8 秒后自动收起）；再次点击可重新触发。
- **滚轮/滚动浏览**：内容进入视口时淡入上移；直接跳转、快速滑动时由滚动兜底逻辑补上，不会停在透明状态。
- **一起跳泥坑**：全家福里的小猪依次起跳，同时落下彩纸和泥点；按钮变成「再来一次！」。
- **回到开头**（页脚）：平滑滚回顶部。
- **减少动态效果**：系统开启「减少动态效果」时，入场动画、彩纸、泥点和摇摆装饰全部停用，内容直接显示。

## 自定义

所有内容都在这一个文件里，改完刷新即可。

- **文案**：搜索角色名（如 `佩奇`）或区块注释，直接替换中文；口头禅在按钮的 `data-say` 属性里，卡片引言在 `.member__quote` 里。
- **颜色**：文件顶部 `:root` 里的 `--pink`、`--blue`、`--orange`、`--red`、`--grass` 等变量控制整套配色。
- **角色插画**：`<defs>` 中 `#pig-peppa`、`#pig-george`、`#pig-mummy`、`#pig-daddy` 是四个可复用 SVG 组；改其中一组，Hero、成员页和全家福会同步更新。
- **明信片**：`.postcard` 里的内联 SVG 可直接换成自己的画或照片；换成图片时给容器加 `overflow:hidden` 和 `border-radius` 即可。
- **全家福**：`#finale` 的 `finale__scene` 是独立 SVG，可整体替换成真实合照（保持 600×360 的比例最稳）。
- **增加成员**：复制一个 `.member` 区块，改 `id`、颜色类（`.member--xxx`）、姓名、标签、引言和 `data-say`，再在 `#finale` 里补一只小猪。

## 技术说明

- 单文件：HTML + CSS + 内联 SVG + 原生 JS，无外部字体、图片、库或构建步骤。
- 动画只用 `transform` / `opacity`；曲线为 `cubic-bezier(0.23, 1, 0.32, 1)`，尊重 `prefers-reduced-motion`。
- 适配 `viewport-fit=cover` 与安全区；输入法缩放无关（页面无输入框）。
- 已测：390×844、320×568（Chrome 157 headless，移动模拟）；无横向溢出、无 JS 报错。
