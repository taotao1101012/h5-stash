# 布鲁伊 · 一家四口｜角色图鉴 H5

单文件 H5，直接双击 `index.html` 就能看；也可以起个本地服务：

```bash
python3 -m http.server 8765   # 然后打开 http://127.0.0.1:8765/index.html
```

线上：https://taotao1101012.github.io/h5-stash/bluey-family/

## 七个画面，一条横轴

全部靠**左右滑动**推进，没有第二种手势方向。

| # | 画面 | 内容 |
| --- | --- | --- |
| 1 | 封面 | 标题 + 布鲁伊与宾果，点「开始探索」进入 |
| 2–5 | 角色 | 班迪 / 琪莉 / 布鲁伊 / 宾果，各占一屏，带「必杀 / 软肋 / 最爱」档案条；每人有自己的背景母题（骨头 / 行李箱 / 球 / 花）和小道具（咖啡 / 行李箱 / 王冠 / 花） |
| 6 | 游戏 | 「今天玩什么」四宫格，点开每个都能真玩 |
| 7 | 全家福 | 一家四口合影，按快门 → 靠拢 → 闪光 → 落成拍立得，可存成 PNG |

## 四个小游戏（同页浮层，不跳新页面）

| 游戏 | 怎么玩 |
| --- | --- |
| 气球不落地 | 布鲁伊在下面跟着球跑，点气球把它顶起来，掉地就结束 |
| 魔法木琴 | 四只狗在上排坐着，谁的音符响了谁就跳一下；听一段照着敲，三关 |
| 纸箱飞船 | 班迪在旁边看着，按住蓄力、松手起飞，看飞多少米 |
| 捉迷藏 | 布鲁伊从边上探进来，五丛草里找宾果，找三轮 |

浮层是从卡片位置缩放开出来的，`Esc` 或右上角 × 关闭，不会离开页面。

## 交互

- 左右滑动 / ← → 键 / 滚轮：翻页
- 顶部七段进度条：点哪段跳哪屏
- 全家福「拍一张全家福」：一声快门，闪光后照片带白边和题注落定；再按是重拍
- 「保存照片」：把照片渲成 1080×1920 PNG（含白边和题注）。手机走系统分享面板，选「存储图像」进相册；桌面直接下载
- 右上角：音乐开关

## 实现说明

- **角色**：`dogMarkup()` 用一套参数化 SVG 画出四只牧牛犬，颜色 / 耳长 / 头宽 / 眼睛大小 / 斑纹位置各不相同。眨眼、摇尾、抖耳、呼吸都由 SMIL 驱动——CSS transform 作用在 SVG 分组上在 WebKit 会把 clipPath 裁错位。
- **音乐**：Web Audio 实时合成的八音盒摇篮曲 + 快门声 + 每个小游戏的音效，没有任何外部音频文件。
- **翻页**：一条 `translate3d` 长卷，`pointer` 拖拽 + 边界阻尼 + 速度/位移判据，没有嵌套滚动。
- **导出**：把场景 SVG 序列化 → `<img>` → canvas 重绘（矢量，不是截屏），所以 1080×1920 始终清晰。

## 改文案

角色文案在 `CHARS` 数组（含 `facts` 档案条），游戏在 `GAMES` 数组，小游戏逻辑在 `gameBalloon / gameXylo / gameRocket / gameHide` 四个函数里。角色图形在 `dogMarkup()`，坐标 240×336。

> 校园练习作品，角色为致敬性的手绘 SVG 再创作，未使用动画原片素材。
