# 布鲁伊 · 一家四口｜角色图鉴 H5

单文件 H5，直接双击 `index.html` 就能看；也可以起个本地服务：

```bash
python3 -m http.server 8765   # 然后打开 http://127.0.0.1:8765/index.html
```

## 结构

| 屏 | 内容 |
| --- | --- |
| 封面 | 标题 + 布鲁伊 & 宾果，点击「开始探索」进入 |
| 角色卡 | 四张卡横向拖拽：班迪 / 琪莉 / 布鲁伊 / 宾果 |
| 合集 | 一家四口竖版全景合影，爸妈在后、两个小朋友在前 |

## 交互

- 上下滑动 / 滚轮 / ↑↓ 键：切换三屏
- 卡片左右拖拽（鼠标指针或手指）、两侧箭头、底部圆点
- 右上角按钮：音乐开关

## 实现说明

- **角色**：`dogMarkup()` 用一套参数化 SVG 画出四只牧牛犬，颜色 / 耳长 / 头宽 / 眼睛大小 / 斑纹位置各不相同。眨眼、摇尾、抖耳由 SMIL `animate` 驱动，卡片的整体呼吸感由 CSS 驱动。
- **音乐**：Web Audio 实时合成的八音盒摇篮曲（C–Am–F–G 循环 + 琶音 + 弱铺底 + 生成式混响），没有任何外部音频文件，所以完全离线可用、也不会踩版权曲目。
- **配色**：每张卡片把自己的 accent / tint 写进 CSS 变量，切卡时整页背景、圆点、气泡一起换色。
- **无障碍**：`prefers-reduced-motion` 下会关掉动画。

## 改文案

所有角色文案集中在文件顶部的 `CHARS` 数组里（名字、身份、标签、台词、配色），改完刷新即可。角色图形在下面的 `dogMarkup()`，坐标是 240×336 的 viewBox。

> 非官方粉丝作品，角色为致敬性的手绘 SVG 再创作，未使用动画原片素材。
