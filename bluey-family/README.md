# 布鲁伊 · 一家四口｜角色图鉴 H5

单文件 H5，直接双击 `index.html` 就能看；也可以起个本地服务：

```bash
python3 -m http.server 8765   # 然后打开 http://127.0.0.1:8765/index.html
```

线上：https://taotao1101012.github.io/h5-stash/bluey-family/

## 四屏

| 屏 | 内容 |
| --- | --- |
| 01 封面 | 标题 + 布鲁伊与宾果，点「开始探索」进入 |
| 02 角色 | 四张卡横向拖拽：班迪 / 琪莉 / 布鲁伊 / 宾果，每张带「必杀 / 软肋 / 最爱」档案条 |
| 03 游戏 | 「今天玩什么」四宫格：气球不落地、魔法木琴、纸箱飞船、捉迷藏 |
| 04 全家福 | 一家四口竖版合影，按快门 → 四人靠拢 → 闪光 → 落成一张拍立得 |

## 交互

- 上下滑动 / 滚轮 / ↑↓ 键：切屏
- 卡片左右拖拽（鼠标指针或手指）、两侧箭头、底部圆点
- 全家福页「拍一张全家福」：会有一声快门，闪光之后照片带白边和题注落定；再按一次是重拍
- 右上角按钮：音乐开关

## 实现说明

- **角色**：`dogMarkup()` 用一套参数化 SVG 画出四只牧牛犬，颜色 / 耳长 / 头宽 / 眼睛大小 / 斑纹位置各不相同。眨眼、摇尾、抖耳、呼吸由 SMIL 驱动（CSS transform 作用在 SVG 分组上在 WebKit 会裁错位，踩过这个坑）。
- **音乐**：Web Audio 实时合成的八音盒摇篮曲（C–Am–F–G 循环 + 琶音 + 弱铺底 + 生成式混响），快门声也是合成的（高通噪声 + 一记铃）。没有任何外部音频文件，离线可用。
- **配色**：每张卡片把自己的 accent / tint 写进 CSS 变量，切卡时整页背景、圆点、气泡一起换色。
- **无障碍**：`prefers-reduced-motion` 下关掉位移动画，只保留淡入。

## 改文案

角色文案集中在文件顶部的 `CHARS` 数组（名字、身份、标签、档案、台词、配色），游戏在 `GAMES` 数组，改完刷新即可。角色图形在 `dogMarkup()`，坐标是 240×336 的 viewBox。

> 校园练习作品，角色为致敬性的手绘 SVG 再创作，未使用动画原片素材。
